## Repository Layout

```txt
api/       NestJS backend
mobile/    Expo React Native app
```

## API Commands

Run from `api/`:

```bash
npm install
npm run start:dev
npm run lint -- --no-fix
npm run test -- --ci --runInBand
npm run build
```

## Mobile Commands

Run from `mobile/`:

```bash
npm install
npm run typecheck
npm test -- --runInBand
```
